# Feature art

These sprites were rendered in Blender (in this repo's pipeline, 2026-11-15) from CC0 Poly Haven
assets (https://polyhaven.com). CC0 means they are free to use for anything; the sources are
listed here anyway. The camera is orthographic and 55 degrees above the ground, and every scene is
stretched so its footprint projects onto the map's pointy-top hex. The renders have transparent
backgrounds and are scaled to 320 px.

| files | made from | notes |
| --- | --- | --- |
| forest_0-3.png | tree_small_02 (Rico Cilliers), 80-92 scattered copies | the client tints them per climate (cold, autumn) |
| jungle_0-1.png | tree_small_02, denser and larger | the client tints them deep green |
| hills_0-2.png | a rolling mound mesh made here, plain grey | laid over the terrain in overlay blend, so they only shade it |
| mountain_0-2.png | boulder_01 (Rico Cilliers), 5-7 copies stretched into peaks | snow added above a height line in Blender |

The Blender scene is in runs/unit_models.blend, which is git-ignored.

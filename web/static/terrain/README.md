# Terrain textures

These are the colour (diffuse) maps of CC0 textures from Poly Haven (https://polyhaven.com),
downloaded at 1k through the Blender add-on on 2026-11-15 and scaled to 512 px. CC0 means they
are free to use for anything, with no attribution required; the sources are listed here anyway.

| file | Poly Haven texture | author | used for |
| --- | --- | --- | --- |
| grass.jpg | rocky_terrain_02 | Amal Kumar | grassland, and plains (graded warmer) |
| dunes.jpg | aerial_beach_01 | Rob Tuytel | desert |
| sand.jpg | aerial_beach_02 | Rob Tuytel | beaches |
| tundra.jpg | rocky_terrain_03 | Amal Kumar | tundra |
| snow.jpg | snow_field_aerial | Rob Tuytel | snow |
| rock.jpg | aerial_rocks_02 | Rob Tuytel | hills and mountains |

The client grades each texture's colour in code (`TERRAIN_PHOTO` in web/static/app.js) to match
the map palette.
